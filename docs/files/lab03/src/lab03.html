7. Show the class() of each variable in the gapminder dataset. Describe the the difference between"numeric", "integer", and "factor" data classes. (2 points)

Answer: Numeric data represent both whole numbers and decimals. Integer data is a special case of numeric data. Integers are numeric data without decimals. Factors are a special case of character data; factor data have a limited number of unique text categories. For instance, continents are factors because there is a limited number of continent categories into which data can be assigned.

11. Which 5 countries have the lowest average life expectancy over the period from 1952 to 2007 (the entire dataset spans these years)? Hint: Use group_by(), summarize(), and order() (2 points)

LifeExp <- gapminder %>% group_by(country) %>% summarise(mean(lifeExp)) #group by country and use a pipe to pass the output to the summarize function to summarize the average life expectancy

LifeExp <- LifeExp[order(LifeExp$`mean(lifeExp)`),] #order the counties by lowest to highest average life expectancy

3. Subsetting and Summarizing Data

Sometimes you are only interested in a specific subset of data. Or you want to quickly group or summarize your data by some specific feature. In this section we’ll work with an imaginary dataset of exam scores and demographics and the dplyr package to go over some useful subsetting and summarizing functions. First, let’s create the dataframe.

# Exam data
exam <- data.frame(
  id = 1:5,
  q1 = c(1, 5, 2, 3, 2),
  q2 = c(8, 10, 9, 8, 7),
  q3 = c(3, 7, 4, 6, 4)
)

# Demographic data
demographics <- data.frame(
  id = 1:6,
  sex = c("f", "m", "f", "f", "m", "x"),
  age = c(25, 22, 24, 19, 23, 40),
  major = c("math", "bio", "math", "art", "art", "geog")
)

# Combine exam and demographics
combined <- merge(x = exam, 
              y = demographics, 
              by = "id")

You can see that most of the data has a numeric class. The exception are the sex and major columns. The class of these columns is factor. Factors are a special character class in R. A factor is a nominal variable that has a well-specified possible set of values that it can take on. For example, one can create a factor sex that can only take on the values “male” and “female”. Factor data are useful because they create discrete groupings that can be used to summarize and subset data.

# Use the aggregate function to summarize the mean score for quiz 1 by sex. Here the "~" operator can be read as "by." So you can read this expression as in the data set combined use the mean function to aggregate quiz1 results by sex. 
aggregate(x = q1 ~ major, 
          data = combined, 
          FUN = mean)
  major  q1
1   art 2.5
2   bio 5.0
3  math 1.5
# You can also add an additional argument to subset the data by a specific condition. Here the data is subset to only include students whose age is greater than 20. 
aggregate(x = q1 ~ sex, 
          data = combined,
          subset = age > 20,
          FUN = mean)
  sex  q1
1   f 1.5
2   m 3.5

Note: In addition to greater than “>”, you can use the less than “<”, equal “==”, and not equal “!=” operators to subset data.

Data sets can contain thousands of entries! Thankfully, R has some great built-in functions like aggregate() that allow you to easily apply functions (like mean()) to a dependent variable for each level of one or more independent variables with just a few lines of code. In addition to aggregate, The dplyr package package allows you to do all kinds of analyses on large datasets quickly and easily. It is especially useful for creating tables of summary statistics across specific groups of data.

Programming with dplyr looks a lot different than programming in standard R. dplyr works by combining objects (dataframes and columns in dataframes), functions (mean, median, etc.), and verbs (special commands in dplyr). In between these commands is a new operator called the pipe which looks like this: %>%. The pipe simply tells R that you want to continue executing some functions or verbs on the object you are working on. You can think about this pipe as meaning ‘and then…’

# Template for using dplyr using the combined dataset as an example 
combined %>%                    # Specify original dataframe
  filter(age > 20) %>%          # Filter condition
  group_by(sex) %>%             # Grouping variable(s)
  summarise(
    q1.mean = mean(q1),         # calculate mean grade for quiz 1
    q2.mean = mean(q2),         # calculate mean grade for quiz 2
    q3.mean = mean(q3)          # calculate mean grade for quiz 3
    ) %>%         
  arrange(q1.mean)              #order the rows of the output by q1.mean
# A tibble: 2 × 4
  sex   q1.mean q2.mean q3.mean
  <chr>   <dbl>   <dbl>   <dbl>
1 f         1.5     8.5     3.5
2 m         3.5     8.5     5.5

4. Replacing Data

Sometimes you need to replace or simplify data categories. One of the most common cases is when you have missing data values. In R missing data values show up as NA.

#Imagine that you have data for a fourth quiz (q4) but 2 students missed this quiz. Their scores are represented as NA.
q4 <- c(6, 7, NA, 9, NA)
combined2 <- cbind(combined, q4)

#You can use the is.na() function to test which values of a vector are missing and replace NA values with another value. In this case we'll replace NA values with 0.
combined2$q4[is.na(combined2$q4)] <- 0

You can also replace numeric and character data in R. Replacing numeric data is similar to replacing no data values.

#replace all scores greater than or equal to 7 for q4 with 100
combined2$q4[combined2$q4 >= 7] <- 100

Replacing character values can present some challanges. What happens when you try to replace a value in the major column?

combined2$major[combined2$major == "art"] <- "BA"

Remember factors are a special class with pre-determined categories. You can’t replace a factor with a value outside the ones they were initially assigned. To replace factor data you need to convert its class to character.

combined2$major <- as.character(combined2$major) #convert major data values from factors to characters 
combined2$major[combined2$major == "art"] <- "BA" #change all art entries in the column to the value "BA"
